# 🚀 Super Tasking Manager

## 📌 Project Overview
A web-based task management application built using HTML, CSS, and JavaScript. It supports task creation, viewing, and editing, with LocalStorage for persistent data storage.

## 🛠️ Technologies Used
- **HTML5:** Application structure.
- **CSS3:** Styling and responsive layout.
- **JavaScript:** Application logic and DOM manipulation.
- **LocalStorage:** Client-side data persistence.

## 📂 Project Structure
```bash
Super-Tasking-Manager/
│
├── index.html
├── style.css
└── app.js
```

## ⚙️ Key Features
- ➕ Create new tasks.
- ✏️ Edit existing tasks.
- 📋 Display saved tasks.
- 💾 Persist tasks using LocalStorage.
- 🔔 Display status and error messages.
- 👤 Update student identification number.
- 🔗 Navigate to the contribution page.
